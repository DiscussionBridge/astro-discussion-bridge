# DiscussionBridge for Astro

Connect your Astro site to Discourse. You can show discussions beside your
articles, send eligible Astro articles to the forum, and publish selected
Discourse topics as pages on your site. The adapter works with plain Astro
and with Starlight.

Start with the [Astro and Starlight setup guide](packages/astro-discussion-bridge/docs/NATIVE_V4.md)
for installation, site configuration, and publishing. [Astro demo](https://astro.demo.discussionbridge.dev/) ·
[Starlight demo](https://astrostarlight.demo.discussionbridge.dev/)

V4 Alpha source [`v0.4.0-alpha.1.astro.3`](https://github.com/DiscussionBridge/astro-discussion-bridge/tree/v0.4.0-alpha.1.astro.3). [Versions and live status](https://docs.discussionbridge.dev/versions-and-live-status/)
