## Simple mode

This page uses `discussionCommentsDisplay: "simple"`.

It delegates comment rendering to Discourse's standard embed script. This is the lightest setup and a good baseline for sites that want the familiar Discourse embed behavior with minimal Astro-side presentation.

This comparison page displays the shared demo discussion without managing the Discourse companion topic.
